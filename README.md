# 스캔 PDF 보정 웹앱

브라우저에서 스캔 PDF의 기울기, 명암, 선명도를 보정하고 PDF로 저장합니다.
GitHub Pages 등 정적 웹 호스팅에서 실행할 수 있습니다. 서버 프로그램이나 실행 파일은 필요 없습니다.

## 기능

- 전체 문서 원클릭: 페이지별 화질 분석 → 밝기·대비·배경 자동 정리 → 페이지별 자동 기울기
- 저장/자동 보정 중 중앙 진행 막대, 진행률, 처리 페이지 수 표시
- 보정 미리보기에서 사각형 드래그로 모자이크/검정 가리기, 영역 취소
- 가리기 영역은 현재 페이지에만 적용되며 각도 변경 후에도 원본 위치를 유지

- 페이지별 또는 전체 자동 기울기 보정 (±5° 탐색)
- 슬라이더, 각도 입력, ±0.1° 수동 조절
- 내용 크기 유지 / 용지 확장 / 전체 맞춤 축소 선택
- 밝기, 대비, 선명도, 배경 밝게, 컬러/회색조/흑백
- 원본과 보정본 미리보기 및 격자선
- 현재 설정 전체 적용, 원본 복귀, 150/200/300 dpi PDF 저장

## 사용

웹 주소를 열고 PDF를 선택 → 보정 → PDF 저장.
PDF 내용은 브라우저 메모리에서 처리하며 서버에 업로드하지 않습니다.
파일 처리 시 사용되는 라이브러리도 사이트 안에 포함됩니다.

## 제한

- 보정된 페이지는 이미지로 저장되어 기존 OCR 글자, 주석, 양식, 링크는 유지되지 않습니다.
- 보정하지 않은 페이지는 원본 페이지를 복사합니다. 전자서명 효력은 유지되지 않습니다.
- 기본 크기 유지 모드는 회전으로 용지 밖에 나가는 가장자리가 잘릴 수 있습니다.
- 용지 확장 모드는 내용 크기를 유지하지만 페이지 크기가 바뀝니다. 인쇄 시 실제 크기를 선택하세요.
- 자동 정리는 페이지별 배경 밝기, 글자 대비, 배경 편차를 분석해 강도를 조절합니다. 깨끗한 페이지와 사진 중심 또는 매우 어두운 페이지는 화질 보정을 최소화하거나 원본을 유지합니다. 뭉개진 글자 복원이나 원근/종이 휘어짐 보정은 지원하지 않습니다.
- 암호 PDF는 지원하지 않습니다. 연한 도장·서명은 결과 확인이 필요합니다.
- 큰 파일은 브라우저의 메모리와 처리 시간이 필요합니다. 입력 250MB 이하.
- 새로고침하면 선택 파일 및 보정 설정이 초기화됩니다.

## 배포

저장소의 main 브랜치 루트를 GitHub Pages 소스로 설정합니다.
index.html, app.js, vendor 폴더를 함께 배포해야 합니다.

## 라이브러리

PDF.js 3.11.174 (Apache-2.0), pdf-lib 1.17.1 (MIT).
PDF.js의 동적 코드 평가는 비활성화되어 있습니다.
라이선스 및 다운로드 파일 SHA-256은 vendor 폴더에 있습니다.
